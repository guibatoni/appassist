# DUELTRACE v0.10.0 — Preview

## Novidades
- **Avisos de atualização:** ao abrir uma versão nova, o DUELTRACE mostra automaticamente o que mudou, mesmo sem internet.
- **Biblioteca de Drops:** os filtros BCD-POW e BCD-TEC substituem listas separadas de B, C e D no sistema original.
- **Versões organizadas:** a numeração oficial da Preview agora avança para v0.10.0, com identificação do build.

## Melhorias
- **Patch Notes:** as notas ficam dentro do pacote instalado e podem ser reabertas no botão Patch notes.
- **Atualização em um clique:** baixar, validar SHA-256, substituir arquivos na mesma pasta e reiniciar continuam disponíveis.
- **Aviso de nova versão:** o indicador Atualizações informa quando existir outra Preview oficial para instalar.

## Correções
- **Sincronização de versões:** o processo de publicação verifica se a versão do aplicativo, o nome da branch e as notas coincidem.
- **Atualização segura:** cada ZIP mantém a verificação de origem, identidade do build, SHA-256 e bloqueio contra downgrade.
- **RANKs preservados:** o agrupamento BCD não modifica pontuações de duelo ou probabilidades das cartas; X15 mantém seus três filtros.
