DUELTRACE Cloud

Seu MultiMod Companion online, conectado ao motor de análise local do Windows.

Conectar ao computador

A interface funciona na internet. O motor continua no seu Windows: nenhuma ISO, BIN, imagem original, Memory Card ou RAM é enviada à hospedagem.

A chave fica apenas na memória desta guia. Não é armazenada nem colocada na URL.

Interface web carregada.

Modo local — sem chave

Para usar o aplicativo no próprio computador sem digitar uma chave, execute o DUELTRACE-Connector.exe e abra o painel local.

Abrir DUELTRACE local

O link local só funciona no Windows onde o Connector está aberto. Alguns navegadores solicitam permissão para acessar a rede local.
